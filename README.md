# Lambda calculus

A simple lambda calculus library for learning purposes.

## Build

```sh
# Simply compile main file and run any examples
g++ ./main.cpp -o main -std=c++23
```

Terms/things Support:
    - Variables
    - Abstraction
    - Application
    - Beta reduction ("normal substitution")
    - Alpha renaming
